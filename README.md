## Project Goals

This project aims to:

- Understand ML algorithms at a **mathematical level**
- Implement algorithms **without using scikit-learn**
- Learn how models work **internally**
- Build strong intuition about:
  - optimization
  - loss functions
  - decision boundaries

---

## Future Additions

Planned algorithms and improvements:

- Gradient Boosting
- K-Means Clustering
- PCA (Principal Component Analysis)
- Neural Networks
- More evaluation metrics
- Visualization utilities

---

## Why Implement ML From Scratch?

Using libraries is easy, but building algorithms yourself helps you understand:

- How optimization works
- Why models behave the way they do
- Where bias and variance come from
- How different algorithms compare internally

This project is mainly for **learning, experimentation, and research**.
